PRACTICE TOOL for Bloodborne (bbport 1.9.5 and newer)
by billymoore

Savestates, cheats and teleport points, in a small menu inside the game.


INSTALL
1. Open the folder with the game program: ...\bbport-windows\bin
   (the folder that has bb-probe.exe in it).
2. Copy pdh.dll and the practice-tool folder into it.
3. Start the game as usual: the launcher, then PLAY.


KEYS
  Home   open / close the menu
  F5     save the game state to the active slot
  F9     load the active slot
Every other action (next slot, teleport points, immortal, infinite stamina...)
has no key until you set one in the menu, Settings tab.

The game can stand still while the menu is open (Settings).
Drag the menu by its title to move it; its size is in Settings.


REMOVE
Delete pdh.dll from the bin folder. The game then runs as before.
Also delete the practice-tool folder if you no longer need your saved states.


GOOD TO KNOW
- Works with new bbport versions too. If the menu says "New bbport version",
  that version was not tested yet: everything stays on, but something may break.
- Saved states are kept in bin\practice-tool\slots and can take a few GB.
- Play offline.
